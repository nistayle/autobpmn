# AutoBPMN - Release v1.3.0 (Review Studio UI/UX Redesign)
**Tanggal Rilis:** 17 Oktober 2026  
**Status:** Latest Release  

---

## Ringkasan Rilis
Rilis v1.3.0 menghadirkan **redesign UI/UX menyeluruh** untuk AutoBPMN yang mentransformasikan aplikasi menjadi **SOP-to-BPMN Review Studio** profesional khusus bagi Business Analyst (BA). Mengacu ketat pada kontrak desain `AGENTS.md`, antarmuka didesain dengan tata letak **tiga kolom (three-column workbench)**, sistem visual modern, tenang, dan siap bisnis (clean enterprise SaaS), tanpa ketergantungan framework CSS eksternal yang berat.

---

## Rincian Perubahan

### 1. Tata Letak Tiga Kolom (Three-Column Studio Layout)
* **Left Sidebar (Panel Kiri)**:
  * Navigasi proyek dan status pemrosesan SOP.
  * Tab input teks narasi SOP dan pengunggah berkas (`.pdf`, `.txt`).
  * Adaptasi label cerdas antara mode Live API (`Ekstrak ke BPMN`) dan Simulasi Prototype (`Jalankan simulasi`).
  * Badge validasi diagram (deteksi anomali, deadlock, dan orphan node).
  * Collapsible JSON viewer untuk `intermediate_graph.json` dengan fitur one-click copy.
  * Tombol toggle panel kiri (`PanelLeftClose` / `PanelLeftOpen`) di top bar.
* **Center Stage (Kanvas Utama)**:
  * Ruang dominan terluas untuk kanvas BPMN interaktif (`bpmn-js/NavigatedViewer`).
  * Grid background bernuansa blueprint slate dengan dot pattern halus.
  * Toolbar kanvas: Zoom In, Zoom Out, Fit to Viewport, Unduh format `.bpmn`, dan Unduh format `.svg`.
  * Legenda visual alur (Mulai, Aktivitas/Task, Keputusan/Gateway, Selesai).
* **Right Detail Panel (Panel Kanan)**:
  * Panel inspeksi multi-tab:
    1. **Sumber Dokumen (`evidence`)**: Menampilkan dokumen sumber, status pipeline, serta daftar node dan aktivitas yang berhasil diekstrak.
    2. **Elemen Terpilih (`element`)**: Inspector interaktif yang otomatis aktif saat node/koneksi diklik pada kanvas BPMN. Menampilkan tipe BPMN, nama aktivitas, ID dengan tombol salin, aktor/role pelaksana, alur masuk (incoming), alur keluar (outgoing), kondisi percabangan, dan tautan bukti SOP.
    3. **Isu & Review (`issues`)**: Menampilkan daftar peringatan alur, potensi deadlock, atau node terisolasi, lengkap dengan badge counter isu.
  * Tombol toggle panel kanan (`PanelRightClose` / `PanelRightOpen`) di top bar dan tombol close internal.

### 2. Integrasi Interaktif bpmn-js Canvas & Element Inspector
* Menghubungkan listener `element.click` pada viewer BPMN ke state `selectedElement`.
* Saat elemen di kanvas diklik, studio otomatis membuka panel kanan dan mengarahkan ke tab **Elemen**, menampilkan metadata detail dan relasi edge secara real-time.
* Tombol batal pilih (deselect) dan tombol salin ID elemen yang terintegrasi ke clipboard.

### 3. Sistem Visual & Design Tokens (`AGENTS.md`)
* **Color Palette**:
  * Background utama: `#FAFAFA` (neutral light mode).
  * Surface: `#FFFFFF` dengan border halus `#E4E4E7` (menghindari shadow tebal/kasar).
  * Accent: Biru-teal profesional `hsl(199 89% 48%)` (`--accent-500: #0ea5e9`).
  * Semantic colors: Hijau lembut untuk sukses, amber untuk peringatan simulasi, dan merah untuk anomali.
* **Typography**:
  * Menggunakan Google Font **Inter** untuk teks antarmuka dan **JetBrains Mono** untuk ID/kode/token.
* **Border Radius & Spacing**:
  * Radius 10px untuk kartu/modal, 8px untuk input dan tombol, 6px untuk badge.
  * Skala spacing standar: 4px, 8px, 12px, 16px, 24px, 32px, 48px.
* **Animasi & Transisi**:
  * Micro-animations cepat dan halus (150ms–200ms) untuk responsivitas maksimal tanpa mengganggu input pengguna.

### 4. Responsivitas & Quality Bar
* **Desktop (>1024px)**: Tiga kolom penuh dengan kanvas BPMN sebagai area utama.
* **Tablet (768px–1024px)**: Sidebar dan panel detail otomatis menyusut secara elegan.
* **Mobile (<768px)**: Sidebar dan panel detail bertransformasi menjadi drawer vertikal; kanvas tetap navigable tanpa horizontal scroll pada resolusi 360px.
* Memenuhi kontras WCAG AA, focus ring yang selalu terlihat, dan tooltip informatif pada seluruh kontrol tombol.
