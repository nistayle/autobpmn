# AutoBPMN - Release v1.0.0 (Initial Core Engine & UI Rebuild)
**Tanggal Rilis:** 16 Oktober 2026  
**Status:** Stable Release  

---

## Ringkasan Rilis
Rilis ini merupakan perombakan menyeluruh pada arsitektur backend ekstraksi LLM, algoritma visual layout BPMN 2.0, serta desain antarmuka pengguna (UI) modern berbasis Vanilla CSS.

---

## Rincian Perubahan

### 1. Multi-Provider LLM Fallback Engine
* **Fallback Chain 3 Lapis**: Sistem mendukung **Google Gemini** $\rightarrow$ **Groq** $\rightarrow$ **OpenRouter**. Jika satu provider limit/error, pipeline otomatis beralih ke provider berikutnya.
* **Bypass Cloudflare 1010**: Menambahkan header `User-Agent: AutoBPMN/1.0` pada client `urllib` untuk mencegah penolakan dari Cloudflare di endpoint Groq.
* **Live Model Discovery**: Mendeteksi model aktif secara dinamis dari API Groq dan OpenRouter untuk menghindari ketergantungan pada model yang telah didepresiasi.
* **Robust .env Reader**: Menambahkan auto-loader yang membaca konfigurasi `.env` dengan format standar `KEY=VAL`, `export KEY=VAL`, maupun PowerShell `$env:KEY="VAL"`.

### 2. Layout BPMN 2.0 Sugiyama (Left-to-Right)
* **Eliminasi Snake Layout**: Mengganti alur berliku (snake/winding) dengan layout horizontal **Left-to-Right** berstandar enterprise BPMN 2.0.
* **DFS Cycle Detection**: Mendeteksi *back-edges* (alur revisi/feedback loop) dan mengalirkannya melalui track clearance khusus di atas diagram agar tidak merusak urutan rank horizontal.
* **Collision-Free Branching**: Percabangan gateway ditempatkan pada track paralel terpisah ($+160\text{ px}$) sehingga elemen cabang tidak saling bertumpuk.
* **Orthogonal Manhattan Routing**: Konektor alur dibentuk dengan sudut siku-siku 90° yang tegas dan presisi.

### 3. Graceful Validation & Synthesis
* Mengubah alur pipeline agar tetap menyintesis diagram BPMN meskipun terdeteksi anomali logika minor (orphan node/deadlock). Pengguna dapat melihat diagram sekaligus laporan validasi di UI.

### 4. UI Modern & Standalone Design System
* **Vanilla CSS**: Menghilangkan ketergantungan utility CSS eksternal yang rentan error dan beralih ke design system murni dengan tipografi Inter & JetBrains Mono.
* **Interactive Canvas**: Navigasi zoom in/out, fit-viewport, legenda elemen proses, dan tombol ekspor langsung ke format `.bpmn` (XML) dan `.svg`.
* **Flexible Input**: Tab switcher untuk input teks narasi dan drag-and-drop berkas dokumen PDF/TXT.

### 5. Otomasi & Panduan
* Menambahkan skrip starter 1-klik `START_AUTOBPMN.bat`.
* Menambahkan `SETUP_GUIDE.md` yang ramah pengguna non-teknis.
* Menambahkan `.gitignore` komprehensif untuk melindungi API keys dan mengecualikan folder virtual environment serta node_modules.
