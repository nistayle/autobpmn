# Catatan Rilis AutoBPMN v1.5.5

**Tanggal Rilis:** 18 Oktober 2026  
**Fokus Utama:** Mengurangi keterlambatan menemukan dan memuat font desain.

## ⚡ Font Diminta Lebih Awal

* Koneksi ke `fonts.googleapis.com` dan `fonts.gstatic.com` dimulai dari HTML awal.
* Stylesheet Inter dan JetBrains Mono dipre-load dan diterapkan secara non-blocking, bukan ditemukan melalui `@import` setelah stylesheet aplikasi dimuat.
* `display=swap` dan fallback system font tetap dipertahankan.

## 🧪 Hasil Pengujian & Verifikasi

* **Frontend Build:** `npm --prefix frontend run build` berhasil.
* **CSS aplikasi:** Tidak lagi memuat `@import` font eksternal.
* **Whitespace:** `git diff --check` bersih.
* **Validasi network/browser:** Belum dilakukan karena Chrome tidak tersedia di lingkungan ini.
