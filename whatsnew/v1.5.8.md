# Catatan Rilis AutoBPMN v1.5.8

**Tanggal:** 18 Oktober 2026  
**Fokus:** UI Review Studio bergaya Notion, tetap memakai workflow dan kontrak API AutoBPMN yang sudah ada.

## Redesign workspace

* Tema gelap menjadi default, tema terang tetap tersedia dan preferensi tema disimpan.
* Topbar 56px menyatukan navigasi Diagram/Sumber/Riwayat, pencarian shortcut, chip Simulasi/Prototype, status simpan, dan kontrol tema.
* Workspace menata sumber SOP (288px), kanvas BPMN fluid, dan Copilot (340px) dengan permukaan datar, border halus, serta aksen lime terbatas.
* Sidebar sumber menampilkan pipeline Ekstraksi → Sintesis → Validasi; opsi Proses ulang/Extend dan form sumber tetap mengikuti state workflow sebelumnya.
* Stage menampilkan statistik langkah dan gateway dari `elementRegistry`, status validasi, serta dock Visual/JSON, Edit, Batal, Simpan, dan menu format ekspor.
* Copilot menggunakan kartu pesan yang terpisah, chip rujukan ringkas `L1`/`L4`, dan saran pertanyaan bertag.
* Banner dan bingkai putus-putus mode simulasi dipindahkan ke chip mode; navigasi `/` dan `/demo` tetap dipertahankan.
* Pada layar kecil sidebar dan Copilot menjadi sheet yang dapat dibuka/ditutup; pengukuran di lebar 360px tidak menunjukkan horizontal overflow.

## Motion dan aksesibilitas

* GSAP core versi 3.13.0 dimuat dari satu CDN setelah first paint; `matchMedia` menghormati reduced motion dan mengurangi durasi untuk layar/perangkat terbatas.
* Jika GSAP gagal dimuat, transisi CSS tetap berjalan; animasi dibatasi pada opacity/transform dan tidak mengubah pan/zoom kanvas BPMN.
* Welcome fade, intro stagger, dock entrance, hover kartu, hitung statistik singkat, serta toast selesai sintesis menggunakan animasi ringan.
* Fokus keyboard terlihat, kontrol panel memiliki label aksesibel, dan loading/sukses diumumkan melalui status live.

## Perilaku yang dipertahankan

* Endpoint `POST /api/synthesize`, field `bpmn_xml`, Ctrl+O/S/0, ekspor `.bpmn`, zoom, toast, mode simulasi/live, viewer JSON, dan mode edit JSON tidak diganti.
* Shortcut Ctrl+S dan tombol Simpan tetap mengekspor diagram BPMN; menu format tambahan tetap tersedia melalui kontrol opsi ekspor.
* Label saran Copilot dirapikan tanpa emoji; prompt dan fungsi API tidak berubah.

## Validasi

* `npm --prefix frontend run build` berhasil.
* `git diff --check` bersih.
* Smoke test browser lokal berhasil: muat contoh SOP, render BPMN, statistik `6 langkah`/`2 gateway`, toast sukses, ganti `/` ↔ `/demo`, buka Edit lalu JSON, dan kembali dari edit.
* Uji responsif 360px menunjukkan lebar dokumen tidak melebihi viewport; drawer Sumber dan Copilot dapat dibuka.
* Lighthouse Performance belum diukur karena Chrome DevTools tidak tersedia pada lingkungan ini.
