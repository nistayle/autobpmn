# AutoBPMN - Release v1.2.0 (URL-Based Mode Routing & Simulation Framework)
**Tanggal Rilis:** 17 Oktober 2026  
**Status:** Latest Release  

---

## Ringkasan Rilis
Rilis v1.2.0 memperkenalkan **sistem routing berbasis URL** yang memisahkan dua mode operasi aplikasi: **Prototype Mode** (simulasi lokal dengan mock data) dan **Real Simulation Mode** (koneksi API backend sesungguhnya). Perubahan ini memudahkan demonstrasi fitur tanpa memerlukan backend aktif, sekaligus menyediakan mode kerja penuh untuk integrasi LLM.

---

## Rincian Perubahan

### 1. URL-Based Mode Routing (`frontend/src/services/api.js`)
* **Fitur baru**: Fungsi `isRealApiMode()` mendeteksi mode operasi berdasarkan URL path (`/demo`), query parameter (`?mode=demo`), atau hash (`#demo`).
* **Prototype Mode (Root `/`)**: Menggunakan `runDemoPipeline()` dari `demoPipeline.js` — mengembalikan mock BPMN XML dan validation data secara instan tanpa koneksi ke backend.
* **Real Simulation Mode (`/demo`)**: Mengirim request POST sesungguhnya ke `http://localhost:8000/api/v1/pipeline/process-text` dan `/process-file` via FastAPI backend.

### 2. Dual-Mode UI Framework (`frontend/src/App.jsx`)
* **State reaktif `isRealMode`** yang otomatis sinkron dengan URL menggunakan `window.history.pushState` dan listener `popstate` (browser back/forward).
* **Fungsi `switchMode(toReal)`** untuk perpindahan seamless antara mode tanpa reload halaman.
* **Prototype Mode**: Seluruh workbench di-wrap dalam `.simulation-outer-frame` dengan border dashed kuning (`#d97706`), banner pengumuman "Simulation Only", dan tombol CTA "Klik di sini untuk prototype asli" yang mengarah ke `/demo`.
* **Real Simulation Mode**: Tampilan normal tanpa border wrapper, badge hijau "Real Simulation · Live Backend" di header.

### 3. Simulation Mode Visual System (`frontend/src/index.css`)
* **`.simulation-outer-frame`**: Container luar dengan padding 10px dan background slate.
* **`.simulation-border-box`**: Border 3.5px dashed amber dengan shadow halus dan border-radius 14px.
* **`.simulation-banner`**: Banner gradient kuning dengan badge uppercase "SIMULATION ONLY" dan tombol aksi biru sky.
* **`.simulation-inner-app`**: Inner container flex agar workbench tetap responsif di dalam frame.
* **`.app-header__status--real`** dan **`.app-header__dot--live`**: Status indicator hijau untuk mode Real Simulation.

### 4. Mock Pipeline Service (`frontend/src/services/demoPipeline.js`)
* **File baru**: Menyediakan `runDemoPipeline()` yang mengembalikan BPMN XML lengkap hasil proses SOP Pengadaan Perlengkapan Kantor, beserta data `intermediate_graph`, `validation`, dan `process_name`.
* Digunakan oleh Prototype Mode agar pengguna bisa langsung melihat hasil proses tanpa memerlukan backend aktif.

### 5. Standalone Viewer Sync (`frontend/public/index.html`)
* Menambahkan container `#simOuterFrame` dan `#simBorderBox` dengan banner dan tombol CTA di viewer standalone.
* Script `updateModeUi()` otomatis mendeteksi URL dan menampilkan/menyembunyikan frame simulasi sesuai mode.

### 6. ESM Module Compatibility (`frontend/package.json`)
* Menambahkan `"type": "module"` untuk menghilangkan peringatan Vite v8 terkait native config loader dan ESM syntax.

### 7. Project Documentation (`AGENTS.md`, `PRODUCT.md`)
* **`AGENTS.md`**: UI/UX Design Contract yang mendefinisikan arah desain, visual system, layout rules, dan quality bar.
* **`PRODUCT.md`**: Dokumentasi produk untuk konteks pengembangan.
