# Catatan Rilis AutoBPMN v1.5.1

**Tanggal Rilis:** 18 Oktober 2026  
**Fokus Utama:** Mengurangi pekerjaan awal browser dan menampilkan status pemuatan yang jelas.

## ⚡ Pemuatan Lebih Efisien

* **Kanvas BPMN sesuai kebutuhan:** `BpmnViewer` tidak dimuat atau dirender ketika belum ada BPMN XML pada file aktif. Workspace kosong tetap menyediakan aksi untuk menambahkan sumber SOP atau mencoba contoh.
* **JSON sesuai kebutuhan:** Workframe JSON hanya dirender saat mode JSON dipilih. Draft JSON tetap dikelola oleh `BpmnViewer`, sehingga isi edit tidak hilang saat kembali ke tampilan visual.
* **Pemisahan fitur:** App, kanvas BPMN, Copilot, Command Palette, pratinjau perubahan, dan BPMN Modeler menggunakan pemuatan bertahap. BPMN Modeler baru dimuat saat pengguna memasuki mode edit.
* **Fixture demo terpisah:** Data pipeline prototype dimuat hanya saat proses demo digunakan.

## ⏳ Loading States

* Shell awal dan fallback React menampilkan status saat workspace dimuat.
* Kanvas, editor BPMN, Copilot, Command Palette, pratinjau perubahan, serta pemrosesan SOP memiliki indikator loading yang sesuai konteks.
