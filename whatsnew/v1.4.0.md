# AutoBPMN v1.4.0 — AI Copilot & Grounded Review Studio Release Notes

**Tanggal Rilis**: 17 Oktober 2026  
**Fokus**: Mengubah panel statis menjadi AI Copilot berbasis grounding SOP, streaming jawaban real-time, validasi sitasi verbatim, dan integrasi shortcut terpadu.

---

## 🚀 Sorotan Fitur Utama

### 1. AI Copilot untuk Business Analyst
* **Dual Mode**: Berjalan mulus di Prototype Mode (simulasi lokal interaktif tanpa kuota API) dan Live Mode (terhubung ke backend FastAPI dengan fallback model Gemini $\rightarrow$ Groq $\rightarrow$ OpenRouter).
* **Grounded & Verifiable**: Setiap jawaban diwajibkan mencantumkan sitasi chunk SOP asli (nomor langkah, pasal, dan kutipan verbatim).
* **Anti-Halusinasi**: Backend memvalidasi sitasi yang dihasilkan LLM terhadap chunk SOP yang benar-benar ada di konteks. Sitasi yang tidak valid otomatis ditolak.
* **Context Limiting**: Membatasi input context window LLM hanya pada maksimal 8 chunk paling relevan berdasarkan query pengguna dan elemen BPMN yang sedang dipilih.

### 2. Streaming Response & Micro-Interactions
* **Real-time SSE Streaming**: Mengalirkan token jawaban per kata dengan indikator visual streaming (*blinking cursor*).
* **Status Updates**: Menampilkan progres tahapan (*retrieving context*, *synthesizing answer*).
* **Quick Prompts**: Tombol pemicu cepat untuk BA:
  - *Temukan celah atau ambiguitas alur dalam SOP*
  - *Jelaskan peran RACI dalam proses ini*
  - *Klarifikasi langkah terpilih ke teks SOP*
* **Follow-up Chips**: Saran pertanyaan lanjutan yang dapat diklik langsung untuk melanjutkan investigasi.

### 3. Koneksi Interaktif Sitasi ke Teks SOP
* Mengklik **Citation Chip** pada jawaban AI Copilot akan langsung mengaktifkan **Citation Highlight Banner** pada panel SOP sebelah kiri, menampilkan teks rujukan persis dari dokumen.
* Memilih node pada kanvas BPMN langsung memunculkan **Context Chip** pada input chat Copilot, sehingga BA dapat langsung menanyakan langkah tersebut tanpa mengetik ulang konteks.

### 4. Overdrive: Command Palette, Walkthrough & Traceability
* **Command Palette (`Ctrl+K`)**: Modal pencarian instan untuk menjelajah semua node proses BPMN, memicu ekspor diagram, navigasi panel, dan mengeksekusi quick prompt AI Copilot dalam hitungan milidetik.
* **Step-Through Walkthrough Player**: Mode simulasi alur proses langkah demi langkah langsung di atas kanvas dengan auto-scrolling, floating control bar (`Space` untuk auto-play, `←`/`→` untuk langkah, `Esc` untuk keluar).
* **Bidirectional Canvas Highlighter (`bpmn-node-pulse`)**: Mengklik sitasi di AI Copilot atau memilih langkah di Command Palette langsung memusatkan kanvas ke node bersangkutan dengan animasi pulsa visual.
* **Header Scorecard & Quick Trigger**: Pill pencarian cepat di header tengah (`Ctrl+K`) dilengkapi badge scorecard live (*e.g., 9 Langkah · 100% Grounded*).

### 5. Peningkatan UX & Canvas Tooling
* **Unified Export Dropdown**: Tombol ekspor diagram disatukan menjadi satu dropdown elegan yang memuat pilihan `.bpmn` (BPMN 2.0 XML) dan `.svg` (vektor grafis).
* **Shortcut Guide Keycaps**: Menampilkan panduan tombol pintas keyboard bergaya *keycap* pada seluruh tombol penting (`[` sidebar, `]` detail, `0` fit view, `+`/`-` zoom, `Alt+B` export, `Ctrl+Enter` submit, `W` walkthrough).
* **BPMN Canvas Color Hierarchy**: Penyegaran warna palet BPMN untuk membedakan secara visual antara User Task (Sky Blue), Service Task (Violet), Start Event (Emerald), dan End Event (Rose).
* **Impeccable Design Quality**: 0 anti-patterns terdeteksi, kepatuhan kontras WCAG AA $\ge 4.5:1$, batas bawah teks fungsional $\ge 11\text{px}$, dan struktur semantik bersih tanpa nested cards.
