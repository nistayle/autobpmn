# Catatan Rilis AutoBPMN v1.5.7

**Tanggal Rilis:** 18 Oktober 2026  
**Fokus Utama:** Mengurangi operasi sinkron `localStorage` pada startup dan saat berpindah tab.

## ⚡ Persistensi Tab Lebih Ringan

* Daftar file dan ID tab aktif kini dipulihkan dari satu snapshot LocalStorage dan daftar file hanya diparse sekali.
* Daftar file hanya diserialisasi dan disimpan ketika data file berubah, bukan pada render awal atau setiap kali tab aktif berubah.
* ID tab aktif disimpan terpisah, sehingga berpindah tab tidak menulis ulang seluruh state diagram.
* Perubahan file dan tab aktif tetap dipersist setelah state terkait berubah.

## 🧪 Hasil Pengujian & Verifikasi

* **Whitespace:** `git diff --check` bersih.
