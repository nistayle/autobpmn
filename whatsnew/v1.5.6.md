# Catatan Rilis AutoBPMN v1.5.6

**Tanggal Rilis:** 18 Oktober 2026  
**Fokus Utama:** Menunda stylesheet kanvas BPMN hingga kanvas benar-benar digunakan.

## ⚡ Gaya BPMN Sesuai Kebutuhan

* Gaya `diagram-js`, `bpmn-js`, dan font ikon BPMN kini diisolasi dari chunk vendor awal dan ikut dimuat saat lazy-loaded `BpmnViewer` dibuka.
* Vite menunggu stylesheet yang terkait dengan chunk dinamis sebelum menampilkan viewer; loading state kanvas tetap melindungi transisi saat viewer disiapkan.
* CSS startup tidak lagi memuat stylesheet BPMN berukuran 32.15 kB (6.28 kB gzip); stylesheet tersebut diunduh bersama viewer saat diperlukan.

## 🧪 Hasil Pengujian & Verifikasi

* **Frontend Build:** `npm --prefix frontend run build` berhasil.
* **Entry HTML:** Stylesheet BPMN tidak lagi ditautkan di HTML startup; diverifikasi lewat output build.
* **Whitespace:** `git diff --check` bersih.
* **Validasi visual browser:** Belum dilakukan karena Chrome tidak tersedia di lingkungan ini.
