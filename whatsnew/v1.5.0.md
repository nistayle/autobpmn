# 🚀 Catatan Rilis AutoBPMN v1.5.0

**Tanggal Rilis:** 17 Oktober 2026  
**Fokus Utama:** Multi-Tab File Management (VS Code Style), Sistem Ekspor/Impor Komprehensif, dan Visual BPMN Modeler.

---

## 🌟 Sorotan Pembaruan (Executive Summary)

AutoBPMN v1.5.0 menghadirkan sistem pengelolaan berkas multi-tab bergaya **VS Code Tabs**, kapabilitas impor/ekspor berbagai format diagram proses, serta **Visual Editor** berbasis `bpmn-js/lib/Modeler`. Sesuai arah produk, sistem AI Edit sementara diarsipkan agar alur kerja Business Analyst tetap intuitif, stabil, dan berfokus pada visualisasi langsung.

### 1. Multi-Tab File Management (VS Code Style)
* **Tab Bar Mirip VS Code:** Kanvas dilengkapi dengan tab bar berkas di bagian atas yang menampilkan seluruh diagram BPMN yang sedang dibuka.
* **Fitur Tab:**
  * Ikon berkas BPMN & judul proses yang dapat diganti nama (*double-click to rename*).
  * Indikator modifikasi (*dirty indicator dot* `•`) yang otomatis muncul ketika diagram diubah dan belum disimpan/diekspor.
  * Tombol tutup tab (`×`) dengan dialog konfirmasi jika berkas memiliki perubahan yang belum disimpan.
  * Tombol `+` untuk membuat tab diagram kosong baru (*Blank Starter Process*).
  * Pintasan keyboard: `Ctrl+W` untuk menutup tab aktif, `Ctrl+S` untuk menyimpan/ekspor cepat.
* **Persistensi Otomatis:** Daftar tab yang terbuka dan status perubahannya otomatis tersimpan di `localStorage`, sehingga diagram tidak hilang saat halaman di-refresh.

### 2. Sistem Impor & Ekspor Komprehensif
* **Buka / Impor Berkas:**
  * Mendukung berkas **BPMN 2.0 XML** (`.bpmn`, `.xml`) dan **AutoBPMN Project Model** (`.json`).
  * Tersedia tombol dialog berkas (*FolderOpen*) serta dukungan **Drag-and-Drop** langsung ke atas tab bar atau kanvas.
  * Berkas yang diimpor otomatis diparsing ke model graf `AutoBPMNGraph` dan divalidasi kaidah strukturalnya.
* **Menu Ekspor Terpadu:**
  * **BPMN 2.0 XML (`.bpmn`):** Berkas XML standar industri yang kompatibel dengan Camunda, Signavio, dan Bizagi.
  * **AutoBPMN JSON Model (`.json`):** Model data graf lengkap berisi daftar node, sequence flows, conditions, dan swimlane actor.
  * **Vektor Grafis (`.svg`):** Gambar vektor resolusi tinggi siap dipasang pada dokumen laporan atau presentasi.

### 3. Visual BPMN Editor (`bpmn-js/lib/Modeler` + Canvas Property Drawer)
* **Mode Tinjau Tetap Tenang:** Kanvas default menyajikan diagram bersih tanpa distraksi palette editing.
* **Mode Edit Visual (Hotkey `E`):**
  * Mengaktifkan *palette* dan *context pad* untuk drag-and-drop node, menghubungkan alur, dan mengubah tipe elemen (*morph wrench*).
  * Kontrol Undo (`Ctrl+Z`), Redo (`Ctrl+Y`), chip validasi BPMN real-time, tombol Batal, dan Simpan Perubahan (`Ctrl+S`).
* **Canvas Property Drawer:** Drawer samping interaktif untuk mengedit nama node, pelaksana (actor), dan kondisi gateway/percabangan.

### 4. Workframe View Mode: Toggle Visual vs JSON
* **Tampilan JSON Dipindahkan ke Kanvas/Workframe:**
  * Area kerja utama (kanvas tengah) kini memiliki kontrol segmented switch: `[ 🔀 Visual | 📄 JSON ]`.
  * Tampilan JSON di sidebar kiri telah dihilangkan sehingga panel SOP extraction menjadi lebih bersih dan fokus pada input teks SOP serta parameter ekstraksi.
  * Saat beralih ke tab **JSON**, workframe menampilkan model data graf terstruktur AutoBPMN lengkap dengan:
    * Penomoran baris (*line numbers*).
    * Pewarnaan sintaks WCAG AA (*syntax highlighting* untuk key, string, boolean, number, dan null).
    * Header metadata dengan statistik instan: jumlah node, sequence flow, dan role/actor.
    * Tombol salin JSON (*Copy to Clipboard*) dengan visual feedback dan tombol unduh langsung.
  * Instance kanvas `bpmn-js` tetap dipertahankan (*kept alive*) di balik layar, sehingga perpindahan antara tampilan Visual dan JSON berlangsung instan tanpa reload diagram.

### 5. Placeholder Kanvas Informatif (Zero-State Hub)
* Saat tidak ada diagram BPMN yang aktif pada tab:
  * Tampil placeholder informatif compact yang memberi tahu status: **"Belum Ada BPMN Aktif"**.
  * **Call-to-Action Utama:** Tombol *"Tambahkan Sumber SOP Sekarang"* dengan animasi panah dinamis yang seketika membuka sidebar kiri dan memfokuskan kursor ke dalam textarea SOP.
  * **Ringkasan Fitur Inti Studio:** Memuat penjelasan compact mengenai Sintesis Otomatis Sugiyama DAG, Visual/JSON Workframe, Visual Modeler, dan Grounded AI Copilot.
  * **Pintasan Keyboard Terpadu:** Kartu ringkasan shortcut keyboard yang sering digunakan (`Ctrl+K`, `Ctrl+Enter`, `Alt+S`, `E`, `W`, `Ctrl+W`, `Ctrl+S`).

### 6. Pengarsipan AI Edit BPMN
* Mekanisme AI patch editing telah diarsipkan dari antarmuka agar tidak menambah kompleksitas kognitif.
* AI Copilot tetap berfokus pada perannya sebagai asisten investigasi SOP, verifikasi aturan bisnis, sitasi kutipan sumber SOP, dan pendeteksi gap kepatuhan proses.

### 7. Alur File dan Sumber SOP Terisolasi
* Tombol file baru menawarkan dua jalur: impor sumber SOP PDF/TXT lokal menjadi diagram baru, atau membuka file BPMN kosong dan menambahkan SOP dari sidebar.
* Sumber teks hasil ekstraksi tersimpan pada file BPMN masing-masing; berkas sumber asli dan riwayat Copilot disimpan di IndexedDB dengan ID file masing-masing sehingga tidak tercampur antar-tab.
* Riwayat percakapan Copilot juga dipisahkan dan dipulihkan per file. Menutup file menghapus sumber asli dan riwayat Copilot file tersebut.
* Proses ulang mengganti diagram pada file aktif. Extend mengusulkan penambahan saja, menampilkan preview validasi, dan hanya mengubah file setelah disetujui.
